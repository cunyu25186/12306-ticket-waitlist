# 模拟 12306 车票候补模块（基础版）

本项目为数据结构与算法课程设计作业。基于 C++ 标准库中的单向队列（`std::queue`），模拟实现了 12306 官方车票候补模块的底层核心逻辑。

---

## 📌 项目背景与核心原则

当旅客遇到无票情况时，可提交候补订单进入系统排队。当系统有退票或新放票时，自动从队头依次兑现出票。

- **先来后到（FIFO）**：严格遵循先进先出原则，新订单只能排在队尾，放票只从队头开始处理。
- **原子性兑现**：单笔订单所需票数必须全额满足才出票，不支持拆单出票。
- **不可跳过队头**：若当前余票不足以满足队头订单所需的票数，本轮放票立即停止，队头订单保留在原地继续等待，**严禁跳过队头给后排旅客出票**（保证公平排队）。

- **编程语言**：C++ (C++11 及以上)
- **核心数据结构**：`std::queue<CandidateOrder>`（单向先进先出队列）
- **数据模型**：

  struct CandidateOrder {

      string passengerName;  // 旅客姓名
